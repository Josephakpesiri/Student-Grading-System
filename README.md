# Student-Grading-System
A Python program that collects and grades the scores of users

The Task:
Build a Student Grading System that asks the user to enter their examination score and assigns a letter grade based on the score.

Your program should:

1️⃣ Ask the user to enter their score.

2️⃣ Use if, elif, and else to determine their letter grade.

3️⃣ Display the score and the corresponding grade.

📊 GRADE BOUNDARIES

Use the following grading system:

* 70–100: Grade A
* 60–69: Grade B
* 50–59: Grade C
* 45–49: Grade D
* 0–44: Grade F
